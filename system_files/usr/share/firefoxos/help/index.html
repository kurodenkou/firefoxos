The Start menu

Click start (or tap the Super key) to open the Start menu. The left side has your pinned programs and the ones you use most. The right side opens your folders, the Control Panel and system tools. All Programs lists everything installed, grouped into folders; you can also just start typing to search.

Web apps

FirefoxOS turns websites into apps with PWAsForFirefox. Each web app gets its own window, taskbar button and Start menu entry, and runs in its own Firefox profile.

  1. Open the site in Firefox.
  2. Click the PWAsForFirefox toolbar button (in the puzzle-piece menu if it's hidden).
  3. Choose Install. The app appears in Start → All Programs → Web Apps.

Manage installed apps in Start → Web Apps. The first time you log in, FirefoxOS downloads the web app runtime in the background. If it didn't finish, run ujust install-webapp-runtime.

Android apps

Android apps run in Waydroid. The first time you open Start → Android Apps, FirefoxOS downloads the Android image for you. You can also run it yourself:

ujust setup-waydroidAndroid without Google apps
ujust setup-waydroid gappsAndroid with the Play Store
ujust waydroid-google-idGet the ID to register a Play Store install
ujust reset-waydroidRemove Android and all its data

Installed Android apps show up in All Programs → Android Apps. Waydroid needs a GPU it supports. NVIDIA cards with the proprietary driver usually don't work.

Installing software

FirefoxOS is an image-based system: the OS itself is read-only and updates as one piece. Install apps as web apps, Android apps or Flatpaks (Control Panel → Add or Remove Programs). For command-line tools, use a toolbox or distrobox container.

Updates

The system updates itself in the background, and the new version takes effect when you restart. To update now, open Control Panel → System Update or run ujust update.

Customizing

The desktop is labwc (window manager), waybar (taskbar) and pcmanfm-qt (desktop icons and wallpaper). Run ujust customize-desktop to copy the defaults into ~/.config, where you can edit them. ujust reset-desktop puts the defaults back.
